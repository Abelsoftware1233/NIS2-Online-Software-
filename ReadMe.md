# 🌐 Online NIS2 Audit Tool (quick-scan variant)

**Zelfstandige web-based scanner met REST API - draait op elke server!**

Let op: dit is een aparte, simpelere tool dan de hoofd-app in de root van dit project
(die heeft wél login, de volledige 40-vragen vragenlijst en PDF-rapportage). Zie de
hoofd-`README.md` voor het verschil tussen beide.

## 🚀 Snelle Start

### Lokaal:
```bash
pip install -r requirements_online.txt
python3 app_online.py
# Open http://localhost:5077
```

De poort is ook te overschrijven via de `PORT` omgevingsvariabele.
